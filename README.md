# Salary Tracker

Приложение на React 18 + Vite для учёта доходов и расходов.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite в терминале.

## Возможности

- Добавление, редактирование и удаление доходов/расходов
- Хранение данных в localStorage
- Общий баланс
- История операций
- Аналитика по категориям
- Доходы/расходы по месяцам
- React Router
- Recharts
- CSS Modules
